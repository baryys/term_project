LEGEND
  ───────────────▷   extends  (inheritance)
  ─ ─ ─ ─ ─ ─ ─ ▷   implements  (interface realisation)
  ───────────────>   uses / depends on
  ◆──────────────    composition  (owner holds lifecycle)
  ◇──────────────    aggregation  (owner references, does not own)

  7. DECORATOR Pattern — City Activity Planning
================================================================================

                  ┌─────────────────────────┐
                  │      <<interface>>       │
                  │       CityActivity       │
                  ├─────────────────────────┤
                  │ + getCity()      : City │
                  │ + getDescription(): String
                  │ + getCost()      : double
                  │ + getRequiredHours():double
                  └─────────────────────────┘
                       △               △
                       │               │   (implements)
              (implements)             │
                       │     ┌─────────┴──────────────────┐
 ┌─────────────────────┐│    │   CityActivityDecorator    │  ← Abstract Decorator
 │  BaseCityActivity   ││    │       <<abstract>>          │
 │  (Concrete Component││    ├────────────────────────────┤
 ├─────────────────────┤│    │ # wrapped : CityActivity   │◇──────> CityActivity
 │ - city : City       ││    ├────────────────────────────┤
 ├─────────────────────┤│    │ # CityActivityDecorator(  │
 │ + getCity()         ││    │     CityActivity)           │
 │ + getDescription()  ││    │ + getCity()                │
 │   "Trip to {name}"  ││    │ + getDescription()         │
 │ + getCost()  → 0.0  ││    │ + getCost()                │
 │ + getRequiredHours()││    │ + getRequiredHours()       │
 │              → 0.0  ││    └────────────────────────────┘
 └─────────────────────┘│                 △
                        │                 │  extends
                        │    ┌────────────┼─────────────┬────────────────┐
                        │    │            │             │                │
                        │ ┌────────┐ ┌────────┐ ┌──────────────┐ ┌──────────────┐
                        │ │Museum  │ │  Park  │ │  Shopping-   │ │  CityCenter  │
                        │ │Visit   │ │ Visit  │ │  MallVisit   │ │   Visit      │
                        │ ├────────┤ ├────────┤ ├──────────────┤ ├──────────────┤
                        │ │+getDes.│ │+getDes.│ │ +getDescr.() │ │ +getDescr.() │
                        │ │+getCost│ │+getCost│ │ +getCost()   │ │ +getCost()   │
                        │ │+getHrs.│ │+getHrs.│ │ +getHours()  │ │ +getHours()  │
                        │ │+$15/3h │ │+$5 /2h │ │  +$100 / 4h  │ │  +$10 / 2.5h │
                        │ └────────┘ └────────┘ └──────────────┘ └──────────────┘
                        │
                  Example decorator chain:
                  new CityCenterVisit(
                    new ParkVisit(
                      new MuseumVisit(
                        new BaseCityActivity(city))))
                  → totalCost = $30, totalHours = 7.5h
